Add photos and videos to your website — no computer needed.

Step 1 — Connect (one time only)

This page saves changes straight to your website. To allow that, paste your website key below. It stays on this phone only — it is never sent anywhere except GitHub when you publish.

  1. On this phone, open github.com and sign in as LoweryLandworks.
  2. Tap your profile picture → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  3. Name it The Work page. Under Repository access choose Only select repositories and pick lowerylandcare.
  4. Under Permissions set Contents → Read and write, and Pull requests → Read and write. Then Generate token and copy it.
  5. Paste it here and tap Save:

Lost it? Just make a new one the same way and paste it again.
