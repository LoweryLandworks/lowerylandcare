Portal photo manager — one-time setup

  1. Open github.com/settings/tokens/new
  2. Note: Lowery portal. Expiration: No expiration (or 1 year).
  3. Check the repo box, scroll down, tap Generate token.
  4. Copy the token (starts with ghp_) and paste it below.

The token stays only in this browser. It lets this page save your changes to the website. You can revoke it anytime at github.com/settings/tokens.
